#Cybersecurity Threat Detection Log Analysis

## Project Overview
This project analyzes cybersecurity threat logs to identify suspicious network activity, blocked connections, and protocol usage patterns.

## Tools Used
- Python
- Pandas
- Matplotlib

## Dataset
Cybersecurity Threat Detection Logs Dataset

## Process
- Missing value detection
- Duplicate detection
- Protocol analysis
- Blocked traffic analysis
- Data visualization

## Insights

* HTTP and HTTPS generated the highest number of blocked events suggesting these
*   these protocols were the primary attack vectors in the dataset.
* Certain source IPs generated significantly higher traffic volumes.
* Such sources indicate potential suspicious activity.


## Results
- Identified most frequently blocked protocols
- Visualized network traffic trends
- Explored protocol distributions

## Skills Demonstrated
Data Analysis, Python Programming, Cybersecurity Analytics, Data Visualization
